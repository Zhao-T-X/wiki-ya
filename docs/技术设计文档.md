# 11. Evolution State Machine

```text
Candidate
   │
   ├── duplicate ──────→ Existing
   │
   ├── coexists ───────→ Active
   │
   ├── supplements ────→ Active
   │
   ├── supersedes ─────→ Active
   │                         │
   │                         └── old Claim becomes non-current
   │
   └── contradicts ────→ Conflict
```

任何状态变化必须通过：

```text
EvolutionService
```

禁止直接 UPDATE status。

# 12. Temporal Query

提供：

```rust
get_current_claims()
get_claims_at(timestamp)
get_claim_history(claim_id)
```

Current：

```sql
WHERE status = 'verified'
AND NOT EXISTS (
    SELECT 1
    FROM claim_relations
    WHERE target_claim = claims.id
      AND relation = 'superseded'
)
```

实际实现必须由 Repository / Query Layer 封装，不允许业务层拼 SQL。

```text

supplements 不改变旧 Claim

supersedes 使旧 Claim 不再 current

contradicts 不自动删除任何 Claim

```

# 92. 最终工程原则

### Rule 1

**Raw is immutable.**

### Rule 2

**Claim is append/evolve, never silently overwrite.**

### Rule 3

**Evidence is first-class.**

### Rule 4

**Current Knowledge is derived.**

### Rule 5

**Ontology is Domain Core.**

### Rule 6

**LLM proposes; Domain validates.**

### Rule 7

**Agent never touches SQL.**

### Rule 8

**Context is budgeted before generation.**

### Rule 9

**IDs are cheaper than payloads.**

### Rule 10

**References are cheaper than repeated context.**

### Rule 11

**Cache is derived state and never blocks execution.**

### Rule 12

**Every AI decision must be inspectable.**

### Rule 13

**Local-first is the default.**

### Rule 14

**New functionality must justify its complexity.**

# 93. 最终验收场景

开发完成后必须能完整跑通：

```text
1. 用户输入一条知识
        ↓
2. wiki-ya 自动提取 Claim
        ↓
3. Resolve Entity
        ↓
4. Search Existing Claims
        ↓
5. 发现旧知识
        ↓
6. 判断 Duplicate / Supplement / Supersede / Conflict
        ↓
7. 生成 Review
        ↓
8. 用户确认
        ↓
9. Commit Evolution
        ↓
10. Timeline 更新
        ↓
11. Search 可以找到当前知识
        ↓
12. History 仍保留旧知识
        ↓
13. Ask 能引用 Evidence
        ↓
14. Agent Context 不携带无关数据
        ↓
15. Context Trace 能解释 Token 消耗
```

如果这条链路跑通：

> **wiki-ya 的核心已经成立。**
